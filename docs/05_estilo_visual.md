# 5. Guía de estilo visual

La interfaz sigue la identidad de la hackathon "Lideresas por el Agua".

## Colores

| Uso | Color |
|---|---|
| Principal | Violeta `#6d61eb` |
| Acentos, subrayados, chips | Verde lima `#cbee79` (solo como fondo, con texto oscuro) |
| Fondos de sección | Lila `#bdadc2`, rosado lila `#f5e9f0` |
| Texto | Azul tinta `#46437e`, azul marino `#1d1b3a` |
| **Semáforo** | Verde, amarillo, naranja y rojo **reservados solo para estados** |

## Tipografía

- Monoespaciada (JetBrains Mono, en línea con Cascadia Code de las bases) para etiquetas, cifras y encabezados en mayúsculas.
- Sans legible para el texto.

## Reglas

1. Cada página abre con una etiqueta, un título y una frase: **qué decisión ayuda a tomar**.
2. El nivel del semáforo siempre lleva **color, palabra e ícono** (accesible para daltonismo).
3. Cada gráfico tiene un título que dice el hallazgo, ejes con unidades y umbrales rotulados.
4. Cada dato indica su origen: **real**, **supuesto**, **simulado** o **demostración**.
5. Contraste WCAG AA; la vista ciudadana usa letra de 18 px o más y se diseña primero para celular.
